# Build v2 — manual, no Gradle

Gradle does not work on the VM used for this build: Gradle 8.5 and 8.7
both fail even for an empty hello project with a fresh GRADLE_USER_HOME,
JDK 17 and --no-daemon, with "Could not receive a message from the daemon /
Unexpected type tag 109". That is a VM daemon-socket failure, not engine
code. So v2 was built manually with aapt2 + javac + d8 + zipalign +
apksigner, reusing the v1 manual host build approach.

## What v2 contains

- `bcore.aar` (1.8 MB): BlackBox engine library. AndroidManifest
  (package top.niunaijun.blackbox), classes.jar (2,697 classes including
  BlackBoxCore and 273 BR* classes generated by the BlackReflection
  annotation processor), res, jni/arm64-v8a/libblackbox.so (300 KB, ELF
  arm64, native core built with NDK r29).
- Host v2 APK (delivered in chat, not committed to this repo, same as v1):
  package com.example.musecontainer, versionCode 2 / 0.2.0-engine,
  minSdk 29, targetSdk 34, apksigner VERIFY_OK, single classes.dex
  (2.7 MB). Launch is wired in Java (no kotlinc on the VM): EngineLauncher
  calls BlackBoxCore doAttachBaseContext / doCreate /
  installPackageAsUser / launchApk, with a shared APK path for all clones,
  lazy install on launch of an ACTIVE clone, and never falls back to the
  normally installed target app. The string NOT_INTEGRATED is absent
  from the dex.
- `manual-aar/`: build-bcore.sh, build-host-v2.sh, merge-manifest.py,
  gen_dep_r.py, host-manifest-v2.xml, host-manifest-v2-base.xml,
  host-src-v2/ (Java host sources for v2). Dependencies are downloaded
  by curl in the scripts (Google Maven for appcompat/material/core/
  constraintlayout, JitPack for BlackReflection core+compiler and
  FreeReflection, Maven Central for javapoet 1.13.0, a transitive
  dependency of the BlackReflection compiler). The deps/, extracted/,
  work-bcore/ and work-host/ directories are build intermediates and are
  not committed.

## What v2 does NOT prove

No phone test has been run. Virtual launch, login inside a clone,
continuous notifications for 2 then 3 active clones, RAM, launch time,
notification delay, battery, background kill, and lag-free operation are
all still unproven and are not claimed. The next step is the phone test
on the Galaxy A23 in order: 2 active clones first, then 3, then 4 only
if 3 passes.

The target APK supplied by the user is never modified, re-signed, or
bundled into the AAR or the host APK.
