# Đóng góp / Contributing

## Góp ý giao diện (không cần biết code) / UI feedback (no coding needed)

Cách được khuyến khích nhất: mở một **Discussion** trong repo để nêu ý tưởng,
hoặc mở một **Issue** bằng mẫu "Góp ý giao diện / UI feedback"
(`.github/ISSUE_TEMPLATE/ui-feedback.yml`).
Ghi rõ màn hình nào, kèm ảnh chụp màn hình (đã che tên tài khoản và nội dung
riêng tư), điện thoại và phiên bản app, vấn đề đang thấy và đề xuất sửa cụ thể.
Gửi góp ý không có nghĩa là chắc chắn được đưa vào bản sau — người duy trì
quyết định cuối cùng.

The preferred way: open a **Discussion** in this repo for an idea, or open an
**Issue** with the "Góp ý giao diện / UI feedback" template
(`.github/ISSUE_TEMPLATE/ui-feedback.yml`).
State which screen, attach a screenshot (with account names and private
content blurred), your phone model and app version, the problem, and a
concrete suggestion. Submitting feedback does not guarantee it will be
included — the maintainer makes the final decision.

## Đóng góp code / Code contributions

1. Fork repo, tạo nhánh riêng cho thay đổi của bạn.
2. Sửa code, rồi mở Pull Request về nhánh `main`.
3. Lưu ý các quy tắc sẵn có của repo:
   - Nhánh `main` được bảo vệ: mọi thay đổi phải qua Pull Request.
   - Không đưa file APK vào cây git — APK chỉ lên GitHub Releases.
   - App mới chỉ được kiểm chứng trên Samsung Galaxy A23 (Android 14),
     nên hãy ghi rõ bạn đã test trên máy nào.

1. Fork the repo and create a separate branch for your change.
2. Make your change, then open a Pull Request to `main`.
3. Existing repo rules:
   - The `main` branch is protected: all changes go through a Pull Request.
   - Do not put APK files in the git tree — APKs go to GitHub Releases only.
   - The app has only been verified on a Samsung Galaxy A23 (Android 14),
     so please state which phone you tested on.
